# Política de seguridad

## Reportar una vulnerabilidad

Envía el reporte a **seguridad@neitek.com** (*por confirmar*) con:
- descripción y pasos para reproducir,
- impacto estimado,
- versión o commit afectado.

No abras issues públicos para vulnerabilidades. Confirmamos recepción en ≤ 2 días hábiles y damos una evaluación inicial en ≤ 5 días hábiles. Coordinamos la divulgación una vez publicada la corrección.

## Alcance
La aplicación de mesa de soporte de este repositorio (API, web, worker) y su configuración de despliegue.

## Fuera de alcance
Ataques de denegación de servicio volumétricos, ingeniería social, hallazgos en servicios de terceros (Microsoft 365, Cloudflare, Azure).

Procedimiento interno: [`docs/seguridad/respuesta-incidentes.md`](docs/seguridad/respuesta-incidentes.md).
